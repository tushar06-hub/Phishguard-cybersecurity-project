# PhishGuard – Phishing Awareness and Detection System

## About the Project
PhishGuard is a web-based cybersecurity awareness and demonstration system developed using PHP, MySQL, HTML and CSS.

It demonstrates phishing awareness, secure authentication and basic phishing detection techniques.

## Features
- User registration with password hashing
- Email-based OTP authentication
- OTP expiry and attempt restrictions
- Rule-based phishing URL detector
- Rule-based phishing email detector
- MySQL database integration
- Security activity dashboard

## Technology Stack
- PHP
- MySQL
- HTML and CSS
- Apache
- Linux Mint
- PHPMailer
- Composer

## Installation
1. Install Apache, PHP and MySQL.
2. Copy the project into the web server directory.
3. Create the `phishguard` database.
4. Import your database schema.
5. Install dependencies using Composer.
6. Configure your local database and SMTP settings.
7. Open `http://localhost/phishguard/`.

## Security Notice
This is an educational prototype, not a production banking application.

Do not upload real passwords, OTPs, SMTP credentials, database credentials or private user data.
